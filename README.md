# Peace Village Phase 3 HOA Website — Version 2

## Publish on GitHub Pages
1. Create a GitHub repository named `peace-village-ph3-hoa`.
2. Upload everything in this folder.
3. GitHub → repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`; folder: `/ (root)`.
6. Save.

## Customize before publishing
- Replace officer placeholders.
- Replace `YOUR-OFFICIAL-EMAIL@example.com`.
- Replace `+63 900 000 0000`.
- Connect Google Forms for Grievance, Document Request, Community Concern and General Inquiry.
- Put approved PDFs inside `documents/` and update their links in `index.html`.
- Put approved photos/logo inside `images/`.
- Publish only documents approved for homeowner/community distribution.

This is a static website. It does not store complaints, passwords, member accounts, or private records. For an actual member login/database portal, connect a secure backend/service separately.
